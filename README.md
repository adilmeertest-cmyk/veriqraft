# Veriqraft

**Where quality meets creation.**

A premium learning and quality-engineering platform by Muhammad Adil. Explore QA engineering, AI workflows, and creative technology; learn through structured courses, practical projects, and assessments; earn verifiable certificates after passing the final assessment.

## Product principles
- Certificates are issued only after passing a course assessment.
- Every certificate has a unique ID and a public QR verification page.
- Student progress and assessment results must be stored securely in a production backend.
- Never publish private client bugs, credentials, or confidential evidence.

## Local development

Install dependencies with `npm install`, then run `npm run dev`.

## Production integrations

Configure Supabase authentication/database, email delivery, and a payment provider before enabling real enrolments, paid courses, or certificate issuance. See `.env.example` and `supabase/schema.sql`.
